# 作品5：用户行为漏斗与 RFM 分析报告

## 1. 分析目标
- 识别用户从曝光到支付的流失节点
- 通过 RFM 完成用户分层，指导运营动作

## 2. 漏斗分析

| 环节 | UV | 环节转化率 |
|---|---|---|
| 曝光 | 1,240 | 100.0% |
| 点击 | 1,240 | 100.0% |
| 加购 | 1,236 | 99.7% |
| 下单 | 1,130 | 91.4% |
| 支付 | 1,130 | 100.0% |

**关键结论**：
- 曝光→点击转化率 100.0%，素材/选品对点击率影响有限；
- 加购→下单转化率 91.4% 是流失最严重环节，常见原因：运费/价格/竞品对比；
- 整体曝光→支付转化率 91.13%。

## 3. RFM 用户分层

| 分层 | 用户数 | GMV(元) | GMV占比 |
|---|---|---|---|
| 一般维持 | 509 | 1,935,110 | 40.6% |
| 高价值用户 | 159 | 1,509,622 | 31.6% |
| 流失用户 | 261 | 522,161 | 10.9% |
| 流失高价值 | 94 | 516,666 | 10.8% |
| 新客/召回潜力 | 107 | 288,196 | 6.0% |

## 4. 运营建议
1. **高价值用户**：建立 VIP 群、专属客服、新品优先体验，防止流失；
2. **流失高价值用户**：定向发放大额召回券（满 300-50），唤醒历史复购；
3. **新客/召回潜力**：首单后 7 天内推送二单优惠，引导完成第二次购买；
4. **加购未下单**：购物车 abandonment 邮件/短信提醒 + 限时折扣；
5. **曝光→点击**：优化主图与首屏文案，A/B 测试不同素材。
